# Telegram Bot для Giga Agent

Telegram бот для доступа к системе Giga Agent. Поддерживает одного пользователя-админа по ID.

## Описание

Этот сервис предоставляет интерфейс Telegram для взаимодействия с системой Giga Agent. Бот проверяет ID пользователя и разрешает доступ только администратору, указанному в переменной окружения `TELEGRAM_ADMIN_USER_ID`.

## Функциональность

- ✅ Проверка прав доступа по ID пользователя
- ✅ Обработка текстовых сообщений
- ✅ Передача запросов в LangGraph API
- ✅ Сохранение контекста диалога (thread_id)
- ✅ Команды для управления диалогом

## Команды

- `/start` - приветствие и информация о боте
- `/help` - справка по использованию
- `/new` - начать новый диалог (сбросить контекст)

## Настройка

### Переменные окружения

В файле `.docker.env` необходимо установить:

```env
# Токен Telegram бота (получить у @BotFather)
TELEGRAM_BOT_TOKEN=your_bot_token_here

# ID пользователя Telegram, который будет иметь доступ к боту (админ)
# Узнать свой ID можно у бота @userinfobot
TELEGRAM_ADMIN_USER_ID=your_telegram_user_id

# URL LangGraph API (по умолчанию: http://langgraph-api:8000)
LANGGRAPH_API_URL=http://langgraph-api:8000
```

### Как узнать свой Telegram User ID

1. Найдите бота @userinfobot в Telegram
2. Отправьте ему любое сообщение
3. Бот вернет ваш User ID (число, например: `123456789`)

## Запуск

Сервис автоматически запускается при старте Docker Compose:

```bash
docker-compose up -d telegram-bot
```

Или вместе со всеми сервисами:

```bash
docker-compose up -d
```

## Использование

1. Найдите вашего бота в Telegram (по имени, которое вы указали при создании у @BotFather)
2. Отправьте команду `/start`
3. Если ваш ID совпадает с `TELEGRAM_ADMIN_USER_ID`, вы получите приветствие
4. Отправляйте текстовые сообщения боту - они будут переданы в систему Giga Agent
5. Бот сохраняет контекст диалога, поэтому можно вести беседу
6. Используйте `/new` для начала нового диалога

## Архитектура

```
Telegram User → Telegram Bot → LangGraph API → Giga Agent System
```

Бот использует LangGraph SDK для взаимодействия с API. Каждый пользователь имеет свой `thread_id`, который сохраняется для поддержания контекста диалога.

## Логирование

Логи бота можно просмотреть через:

```bash
docker-compose logs -f telegram-bot
```

## Ограничения

- Поддерживается только один пользователь-админ
- Доступ проверяется по Telegram User ID
- Длинные ответы автоматически разбиваются на части (лимит Telegram: 4096 символов)
