# Юридический помощник (Lawyer Agent)

Специализированный агент для работы с правовыми актами и кодексами Российской Федерации на основе RAG (Retrieval-Augmented Generation).

## Описание

Юридический помощник использует логику поиска актов из проекта `lawyer_helpers_base` для:
- Определения кодекса по запросу пользователя
- Поиска релевантных статей в кодексах
- Извлечения контекста из найденных статей
- Генерации ответов на основе правовых актов

## Рабочие папки

- **Папка с текстовыми файлами актов**: `law/` в корне проекта
  - Здесь размещаются исходные текстовые файлы кодексов и правовых актов
  - Структура: `law/акты/` или `law/` с подпапками по типам актов
  
- **Векторное хранилище**: `vector_store/` в корне проекта
  - **SQLite БД**: `vector_store/codexes.db` - структурированная БД с кодексами, статьями, главами и разделами
  - **FAISS индекс**: `vector_store/index.faiss` - векторный индекс для семантического поиска
  - **Метаданные**: `vector_store/index.pkl` - метаданные для векторного индекса
  - Все файлы создаются автоматически при первом использовании или загружаются, если уже существуют

## Автоматическая инициализация БД

При первом использовании агент автоматически:

1. **Проверяет наличие БД кодексов** (`vector_store/codexes.db`)
   - Если БД нет, загружает кодексы из текстовых файлов в папке `law/`
   - Ищет файлы в `law/акты/` или `law/` (рекурсивно)
   - Парсит структуру кодексов (разделы, главы, статьи)
   - Сохраняет в SQLite БД

2. **Проверяет наличие векторного хранилища** (`vector_store/index.faiss`, `vector_store/index.pkl`)
   - Если векторного хранилища нет, создает его из статей БД
   - Использует embeddings для семантического поиска
   - Сохраняет в папке `vector_store/`

3. **Проверяет новые файлы**
   - При каждом запуске проверяет, есть ли новые или измененные файлы в `law/`
   - Автоматически обновляет БД при обнаружении новых файлов
   - Обновляет векторное хранилище при изменении БД

## Логика работы

1. **Маппинг кодекса**: Определяет кодекс(ы) по запросу пользователя
   - Сначала проверяет явные указания (УК РФ, Уголовный кодекс и т.д.)
   - Затем проверяет по ключевым словам (уголовное дело, гражданский процесс и т.д.)

2. **Очистка запроса**: Удаляет слова-якоря (названия кодексов, общие юридические термины)

3. **Формирование ключевых слов**: Извлекает и ранжирует ключевые слова по приоритету
   - HIGH: специальные юридические термины (апелляция, кассация)
   - MEDIUM: важные юридические понятия (жалоба, иск)
   - LOW: общие юридические термины

4. **Поиск статей**: Ищет статьи в кодексах по ключевым словам
   - Приоритет статей с высоким уровнем приоритета
   - Сортировка по релевантности (совпадения в названии имеют больший вес)

5. **Векторный поиск**: Дополняет результаты семантическим поиском через FAISS
   - Использует embeddings для поиска похожих документов
   - Объединяет результаты с поиском по ключевым словам

6. **Извлечение контекста**: Формирует контекст из найденных статей

7. **Генерация ответа**: Формирует ответ на основе контекста (требует интеграции с LLM)

## Использование

Агент интегрирован в систему и доступен через инструмент `lawyer_agent`:

```python
# Пример использования
result = await lawyer_agent(
    user_request="расскажи про подачу апелляционной жалобы по уголовному делу",
    user_id="user123"
)
```

## Примеры запросов

- "расскажи про подачу апелляционной жалобы по уголовному делу"
- "как обжаловать решение суда по гражданскому делу"
- "статья 389.1 УПК РФ"
- "порядок подачи иска в суд"
- "какие права у обвиняемого"
- "сроки обжалования приговора"

## Зависимости

- SQLAlchemy (для работы с БД)
- langchain (для работы с документами и векторными хранилищами)
- langgraph (для графа агента)
- faiss-cpu или faiss-gpu (для векторного поиска)
- sentence-transformers (для embeddings)

## Примечания

- **Автоматическая загрузка**: Агент автоматически загружает кодексы из папки `law/` при первом использовании
- **Структура папки law**: 
  - Рекомендуется: `law/акты/` с текстовыми файлами кодексов
  - Альтернатива: `law/` с текстовыми файлами (рекурсивный поиск)
- **Формат файлов**: Текстовые файлы (.txt) с кодексами
- **Кодировка**: Поддерживаются windows-1251, utf-8, cp1251, latin-1
- **Обновление БД**: При добавлении новых файлов в `law/` БД обновляется автоматически
- **Векторное хранилище**: Создается автоматически из статей БД при первом использовании
