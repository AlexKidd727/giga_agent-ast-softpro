# Инструмент для чтения документов (read_document)

Универсальный инструмент для чтения документов различных форматов без необходимости использования REPL.

## Поддерживаемые форматы

- **PDF** (.pdf) - использует PyPDF2 или pdfplumber
- **DOCX** (.docx) - использует python-docx
- **DOC** (.doc) - использует textract или python-docx
- **RTF** (.rtf) - использует striprtf
- **TXT** (.txt) - читает как обычный текстовый файл (поддержка различных кодировок)

## Использование

### Базовое использование

```python
# Чтение PDF файла
text = await read_document("resume.pdf")

# Чтение DOCX файла
text = await read_document("/files/documents/report.docx")

# Чтение PDF с ограничением количества страниц
text = await read_document("large_document.pdf", max_pages=10)

# Чтение большого текстового файла с ограничением размера
text = await read_document("large_document.txt", max_chars=100000)
```

### Чтение из URL

```python
# Чтение документа по URL
text = await read_document("https://example.com/document.pdf")
```

## Параметры

- `file_path` (обязательный) - Путь к файлу документа (локальный путь или URL)
- `max_pages` (опциональный) - Максимальное количество страниц для чтения (только для PDF). Если не указано, читаются все страницы.
- `max_chars` (опциональный) - Максимальное количество символов для чтения. Если не указано, читается весь файл (до 200000 символов). Для полного чтения больших файлов используйте None или большое значение.

## Возвращаемое значение

Строка с текстом документа. По умолчанию читается весь файл до 200000 символов. Для файлов больше 200000 символов текст обрезается с указанием количества пропущенных символов. Можно указать параметр `max_chars` для явного ограничения размера.

## Обработка ошибок

Инструмент возвращает строку с описанием ошибки, если:
- Файл не найден
- Формат файла не поддерживается
- Не установлены необходимые библиотеки
- Файл поврежден или пуст

## Требуемые библиотеки

Для полной функциональности установите:

```bash
pip install PyPDF2 python-docx striprtf
# Опционально для лучшей поддержки PDF:
pip install pdfplumber
# Опционально для поддержки старых DOC файлов:
pip install textract
```

## Интеграция с карьерным агентом

Карьерный агент автоматически использует этот инструмент для чтения резюме в форматах PDF, DOCX, DOC и RTF.

## Примеры использования в запросах

- "Извлеки текст из документа report.docx"
- "Прочитай первые 5 страниц из large_document.pdf"
