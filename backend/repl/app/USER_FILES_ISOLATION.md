# Изоляция файлов по пользователям

## Описание

Все файлы пользователей изолированы по `user_id` для обеспечения безопасности и предотвращения смешивания данных между пользователями.

## Структура хранения

```
files/
├── {user_id_1}/
│   ├── file1.pdf
│   ├── file2.docx
│   └── ...
├── {user_id_2}/
│   ├── file1.pdf
│   └── ...
└── .files_metadata.json  # Метаданные файлов
```

## Реализация

### 1. Утилиты (`user_files_utils.py`)

- `get_user_files_dir(user_id)` - получает путь к папке пользователя
- `get_user_file_path(user_id, filename)` - получает полный путь к файлу пользователя
- `resolve_file_path(file_path, user_id)` - разрешает путь с учетом user_id
- `_validate_user_id(user_id)` - валидирует user_id

### 2. Upload Server (`upload_server.py`)

Все эндпоинты требуют аутентификации и используют `user_id`:

- `POST /upload/` - загружает файл в папку пользователя
- `POST /api/knowledge/files/upload` - загружает файл с метаданными
- `GET /api/knowledge/files` - возвращает только файлы текущего пользователя
- `GET /files/{filename}` - возвращает файл только из папки пользователя
- `PUT /api/knowledge/files/{file_path}/metadata` - обновляет метаданные только для файлов пользователя

### 3. Инструменты

- `read_document` - читает документы из папки пользователя
- `transcribe_audio` - обрабатывает аудио из папки пользователя
- `_read_file_content_safely` - читает файлы с учетом user_id

## Безопасность

1. **Валидация user_id** - все невалидные значения (`default_user`, `anonymous`, `guest`) отклоняются
2. **Изоляция путей** - файлы сохраняются только в папке пользователя
3. **Проверка доступа** - при чтении файлов проверяется, что файл находится в папке пользователя
4. **Path traversal защита** - проверка на небезопасные символы в путях

## Использование

### Загрузка файла

```python
# Файл автоматически сохраняется в files/{user_id}/filename
POST /upload/
Headers: Authorization: Bearer <token>
Body: multipart/form-data с файлом
```

### Чтение файла

```python
# Инструмент автоматически ищет файл в папке пользователя
await read_document("resume.pdf", state={"user_id": "user123"})
```

## Миграция существующих файлов

Существующие файлы в корне `files/` остаются доступными для обратной совместимости, но новые файлы сохраняются только в папках пользователей.
