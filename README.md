## О проекте

Это расширенная версия GigaAgent с множеством улучшений и новых возможностей. Проект содержит значительные улучшения по сравнению с базовой версией, включая многопользовательскую систему, оптимизацию контекста, новые агенты и инструменты.

Подробное сравнение с базовой версией доступно в файле [IMPROVEMENTS_COMPARISON_TABLE.md](IMPROVEMENTS_COMPARISON_TABLE.md)

## Ключевые особенности

### 🚀 Новые агенты и субагенты

- **Финансы**: `tinkoff_agent` - работа с личным брокерским счетом Tinkoff Invest
- **Календарь**: `calendar_agent` - управление событиями Google Calendar
- **Email**: `email_agent` - работа с электронной почтой
- **Код**: `coder_agent`, `coder_plan`, `coder_generate` - генерация прототипов проектов
- **Соцсети**: `social_media_agent` - управление контентом в социальных сетях (для администраторов)
- **Карьера**: `career_agent` - помощник в карьерном развитии
- **Юриспруденция**: `lawyer_agent`, `prepare_response_document` - юридический помощник
- **Браузер**: `browser_task` - автоматизация работы с браузером

### 🛠️ Новые инструменты

- Работа с документами: `read_file`, `extract_archive`, `list_archive_contents`
- Анализ кода: `code_review`, `send_file_to_repl`, `send_file_to_llm`
- GitHub: `create_github_repository`, `publish_project_to_github`
- MySQL: `mysql_query` (с пользовательскими секретами)
- OpenRouter: управление моделями через OpenRouter API
- Провайдеры: переключение между различными LLM провайдерами
- Персонализация: `personalize` - персонализация ответов на основе предпочтений пользователя

### 👥 Многопользовательская система

- Полная изоляция данных между пользователями
- Персональные настройки и предпочтения
- Система прав доступа (администраторы и обычные пользователи)
- Управление чатами с сохранением истории
- Персональные токены для различных сервисов (Tinkoff, GitHub, Google Calendar, Email, MySQL)
- Контекстные инструкции для каждого пользователя

### ⚡ Оптимизация промптов и контекста (ROMA)

- **Модульная система промптов**: загрузка только необходимых модулей (экономия до 97% токенов)
- **Классификация запросов**: автоматическая классификация для оптимальной загрузки модулей
- **Context Offloading**: сохранение больших результатов в файлы с превью в контексте
- **MECE типы задач**: классификация для выбора оптимальной модели

### 🔧 Новые сервисы и компоненты

- **browser-service**: микросервис для автоматизации работы с браузером (WebSocket + HTTP API)
- **telegram-bot**: Telegram бот для доступа к системе (только для администраторов)
- **Система миграций БД**: автоматические миграции базы данных при запуске
- **STT Service**: интеграция сервиса распознавания речи
- **Embeddings Service**: интеграция сервиса векторных эмбеддингов
- **DeployHub MCP**: MCP сервер для работы с проектами

### 🏗️ Улучшения архитектуры

- Hot-reload режим для разработки
- Улучшенная обработка ошибок с понятными сообщениями
- Автоматическая нормализация параметров инструментов
- Фильтрация инструментов по правам пользователя и наличию токенов
- Расширенная поддержка MCP с HTTP транспортом и правами доступа
- Улучшенная конфигурация Docker Compose

### 🎨 Улучшения фронтенда

- Переработанная страница настроек с вкладками
- Интерфейс управления чатами
- Персональные настройки пользователя

## Быстрый старт

### Запуск в Docker

Перед запуском:

* Установите [LangGraph CLI](https://pypi.org/project/langgraph-cli/):

   ```sh
   pip install langgraph-cli
   ```

* Скопируйте мок-данные в папку `files` в корне проекта:

  ```sh
  make init_files
  ```

Чтобы запустить GigaAgent:

1. В корне проекта заполните файл `.docker.env` с переменными окружения.

   Примеры заполнения `.docker.env` — в папке [`env_examples`](env_examples/README.md)

2. Соберите Docker-образ сервера LangGraph:
   
   ```sh
   make build_graph
   ```
3. Запустите приложение:

   ```sh
   docker compose up -d
   ```

Приложение будет доступно в браузере по адресу `http://localhost:8502`

### Локальный запуск

Перед запуском:

* Убедитесь, что у вас свободны необходимые порты
* [Установите менеджер пакетов uv](https://docs.astral.sh/uv/getting-started/installation/)
* [Установите менеджер пакетов npm](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm)
* Скопируйте мок-данные в папку `files` в корне проекта:

  ```sh
  make init_files
  ```

Подробные инструкции по локальному запуску см. в [README_BASE.md](README_BASE.md)

## Настройка

### Переменные окружения

Основные переменные окружения для работы GigaAgent задаются в файлах `.env` или `.docker.env` в корне проекта.

В папке [env_examples](env_examples/README.md) вы найдете шаблоны файлов с переменными окружения.

### Специализированные модели LLM

Проект поддерживает специализированные модели для разных задач:

* **GIGA_AGENT_LLM** — основная LLM для основных агентов
* **GIGA_AGENT_LLM_CODER** — модель для генерации кода
* **GIGA_AGENT_LLM_REPL** — модель для работы в REPL-среде
* **GIGA_AGENT_LLM_IMAGE** — модель для генерации изображений
* **GIGA_AGENT_LLM_FAST** — быстрая/дешевая LLM для скрейпинга

### Оптимизация промптов

Для включения/выключения оптимизации промптов используйте переменную:

* **PROMPT_OPTIMIZATION** — включение модульной системы промптов (экономия до 97% токенов)

### Context Offloading

Настройка сохранения больших результатов в файлы:

* **GIGA_AGENT_CONTEXT_OFFLOAD_THRESHOLD_CHARS** — порог для сохранения (по умолчанию 20000 символов)
* **GIGA_AGENT_CONTEXT_OFFLOAD_PREVIEW_CHARS** — размер превью в контексте (по умолчанию 2000 символов)

### MCP конфигурация

Расширенная поддержка MCP серверов через переменную окружения:

* **GIGA_AGENT_MCP_CONFIG** — JSON конфигурация MCP серверов
* **GIGA_AGENT_MCP_ADMIN_ONLY_TOOLS** — список MCP инструментов, доступных только администратору

Поддержка HTTP транспорта и заголовков авторизации для внешних MCP серверов.

### Поддержка провайдеров

Проект поддерживает переключение между различными LLM провайдерами:

* GigaChat
* OpenAI
* Anthropic
* OpenRouter (с поддержкой множества моделей)
* DeepSeek Reasoning (V3.2)

### Подключение сервисов

Для работы различных агентов требуется настройка токенов:

* **Tinkoff Invest**: токен для работы с брокерским счетом
* **Google Calendar**: OAuth токены для работы с календарем
* **Email**: настройки SMTP/IMAP для работы с почтой
* **GitHub**: токен для работы с репозиториями
* **MySQL**: настройки подключения к базе данных

Токены хранятся персонально для каждого пользователя.

Подробнее о подключении сторонних сервисов см. в [README_BASE.md](README_BASE.md)

## Архитектура проекта

Проект использует микросервисную архитектуру:

- **GigaAgent** — основной агент с многопользовательской поддержкой
- **SubAgents** — специализированные субагенты для различных задач
- **REPL** — контейнер с REPL-средой для выполнения кода
- **ToolServer** — сервер для выполнения инструментов
- **browser-service** — микросервис для автоматизации браузера
- **db-migrations** — отдельный сервис для миграций БД
- **telegram-bot** — Telegram бот для администраторов
- **PostgreSQL** — база данных для хранения пользователей, чатов и настроек
